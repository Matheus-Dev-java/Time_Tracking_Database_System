# Pokedex Database System

## Descrição do Projeto
Este projeto consiste no desenvolvimento de um banco de dados relacional 
para o gerenciamento de uma Pokédex, armazenando informações sobre espécies 
de Pokémon (tipos e atributos base) e sobre Pokémons individuais capturados 
(IVs, EVs, gênero, shiny e pokerus). O projeto é desenvolvido ao longo da 
disciplina de Banco de Dados, evoluindo em complexidade a cada etapa.

## Objetivo da Solução
Modelar e implementar um banco de dados normalizado que represente de forma 
consistente as relações entre espécies e indivíduos capturados, aplicando 
conceitos de chaves primárias, chaves estrangeiras, restrições de integridade 
(constraints) e organização de scripts SQL por categoria (DDL, DML e DQL).
